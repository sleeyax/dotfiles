# Packages installed by scripts/apply.sh on an apt device, via apt-get.
# One package per line; '#' starts a comment.
# Grouped by subsystem so dropping a subsystem is deleting a labelled block.
#
# This is packages.txt under the names apt knows, for aardwolf and nothing else.
# There is no graphical counterpart to this file because there is no graphical
# apt machine: packages.graphical.txt names Arch packages throughout, and only a
# GRAPHICAL=1 device ever reads it.
#
# Three entries of packages.txt have no line here. Two are things a headless
# Ubuntu box has no use for: pacman-contrib is Arch's own, and libsecret backs a
# desktop keyring. The third, oh-my-posh, is wanted here and simply has no apt
# package, so install_oh_my_posh in scripts/apply.sh fetches the release binary
# instead — see the prompt block in home/.config/zshrc/20-customization.
